TDB v7.0.1 — GAMEPLAY FIX

FOCO
- preservar o Visual Rebuild da v7
- corrigir regressões que cobriam ou colapsavam superfícies jogáveis
- renomear TDB JOGOS para TDB
- renomear TDB Lounge para TDB Lobby

CAUSA PRINCIPAL
A v7 adicionou uma skin visual carregada depois dos estilos antigos. Alguns seletores alteravam também a geometria dos módulos:
- Truco: `.table-shell` foi de `height:100%` para `height:auto`, embora seus elementos sejam majoritariamente absolutos;
- Xadrez: `.chess-center` foi trocado de grid para flex, contrariando o cálculo de altura do tabuleiro;
- TDB Lobby: `.music-main` ganhou uma linha extra fixa mesmo sem screen share ativo;
- o overlay de sincronização antigo podia permanecer como uma superfície escura sobre o jogo;
- Blackjack ainda usava margens negativas para empilhar cartas.

CORREÇÕES
TRUCO
- restaura `table-shell` com altura real de 100%
- play zone, mão e ações explicitamente visíveis
- ordem de camadas protegida

XADREZ
- centro restaurado para grid de 4 linhas
- board-shell com área útil real
- tabuleiro 8×8 com proporção 1:1
- casas e peças forçadas visíveis

TDB LOBBY
- stage de screen share inativo usa `display:none`
- player/biblioteca usam duas linhas quando não há transmissão
- player YouTube explicitamente visível

BLACKJACK
- margens negativas removidas
- gap real entre cartas
- quebra de linha permitida para mãos longas

SINCRONIZAÇÃO
- overlay não escurece mais a tela inteira
- render dos quatro módulos chama `hideLoading()`
- observer também remove loader quando uma tela jogável é montada
