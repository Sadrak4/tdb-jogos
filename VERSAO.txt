TDB JOGOS v6.1 — TDB Lounge + Compartilhamento de Tela

TDB LOUNGE
- TDB Music foi renomeado visualmente para TDB Lounge
- o id interno continua `music` para preservar banco/lifecycle
- música, chat e compartilhamento de tela ficam na mesma sala

COMPARTILHAMENTO DE TELA
- botão Compartilhar tela dentro do Lounge
- navegador permite escolher monitor inteiro, janela ou aba
- captura usa getDisplayMedia do navegador
- áudio da tela/aba é enviado quando o navegador/sistema disponibiliza essa opção
- somente 1 transmissão ativa por sala nesta primeira versão
- quem não clicar em Visualizar transmissão não recebe o vídeo
- viewer pode fechar sem encerrar a transmissão para os outros
- transmissor vê quantidade de espectadores/solicitações
- botão Tela cheia para quem assiste
- ao parar pelo navegador ou pelo TDB, a transmissão encerra
- se transmissor cair, heartbeat expira o estado automaticamente

TECNOLOGIA
- WebRTC P2P para mídia
- Supabase/tdb_shared apenas para sinalização, nunca para transportar vídeo
- STUN público configurado por padrão
- suporte opcional a TURN via variáveis de ambiente para redes restritas

BANCO
- nenhuma migração SQL nova
